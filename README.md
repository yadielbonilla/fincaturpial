# GitHub Pages Starter Project

This is a simple static website project created locally for deployment through GitHub Pages.

## Local development

Open `index.html` in a browser or use a local static server.

## GitHub deployment

1. Create a GitHub repository.
2. Push the local repo to GitHub.
3. In the repository settings, enable GitHub Pages.
4. Choose the main branch as the source.

## Files

- `index.html` — site markup
- `styles.css` — site styling
- `script.js` — site behavior
